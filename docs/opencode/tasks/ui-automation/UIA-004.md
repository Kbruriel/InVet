# UIA-004 — UI/E2E automation for FE-004 (Public clinic/branch profile)

## Objetivo

Automatizar pruebas de interfaz para el perfil público y protegido de clínicas/sucursales.

## Dependencias

- Frontend: `FE-004`
- QA: `QA-004`
- Backend: `BE-004`

## Alcance

- Pruebas E2E del perfil público de sucursal en `/clinics/[id]` (BranchProfile).
- Pruebas E2E del perfil protegido en `/clinics/[clinicId]/branches/[branchId]`.
- Pruebas del detalle de clínica pública en `/clinics/[id]` (PublicClinicDetailPage).
- Estados UX: loading, error, empty, success.
- Secciones: servicios, horarios, calificaciones, disponibilidad, CTA.
