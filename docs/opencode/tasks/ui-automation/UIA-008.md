# UIA-008 — Automatizacion UI del flujo de citas / Appointment scheduling automation

## Alcance

Validar el flujo end-to-end de citas mediante pruebas automatizadas con Playwright (dentro de `InVet_UI_Automation/tests/`).

## Casos de prueba

### C1: Propietario solicita cita exitosamente
| Campo | Valor |
| --- | --- |
| ID | UIA-008-C01 |
| Objetivo | Verificar que un propietario puede crear una cita desde el formulario. |
| Precondicion | Propietario autenticado con mascota registrada (BE-007). |
| Pasos | 1. Navegar a /portal/owner/appointments/new. 2. Seleccionar mascota del dropdown. 3. Seleccionar tipo de cita (consulta_general). 4. Seleccionar fecha/hora disponible. 5. Agregar motivo "Revision anual". 6. Click en "Solicitar cita". |
| Esperado | Cita creada con status=pending. Toast/confirmacion visible. Redireccion a agenda o persistencia en la lista. |
| Rol | UIA-008 |

### C2: Propietario ve su agenda con filtros
| Campo | Valor |
| --- | --- |
| ID | UIA-008-C02 |
| Objetivo | Verificar que el listado de citas del propietario funciona y filtra correctamente. |
| Precondicion | Propietario tiene >= 5 citas en diferentes estados. |
| Pasos | 1. Navegar a /portal/owner/appointments. 2. Click en tab "pendientes". 3. Click en tab "completadas". 4. Click en tab "canceladas". |
| Esperado | Cada filtro muestra solo citas de ese estado. Total de items coincide con datos backend. Paginacion funcional. |
| Rol | UIA-008 |

### C3: Clinica aprueba y confirma una cita
| Campo | Valor |

| Precondicion | Clinica autenticada con citas pendientes asignadas. |
