# UIA-016 — UI Automation para Administracion inicial del sistema

## Alcance de la automatizacion

Este artefacto cubre los flujos visuales y de navegacion del slice 016 (administracion inicial) a traves de pruebas E2E en navegador real con Playwright. No prueba contratos HTTP directos (eso corresponde a `APIA-016`).

## Rutas cubiertas por esta automatizacion

| Ruta | Accion verificada | Metodo backend correspondiente |
| --- | --- | --- |
| `/portal/admin/users` | Listar/Detalle/Crear/Desactivar | GET/POST/PATCH /api/v1/admin/internal-users |
| `/portal/admin/clinics` | Listar/Crear | GET/POST /api/v1/admin/clinics |
| `/portal/admin/settings/terms` | Leer/Editar | GET/PUT /api/v1/terms |
| `/portal/admin/settings/privacy` | Leer/Editar | GET/PUT /api/v1/privacy |
| `/portal/admin/reports` | Consultar agregados | GET /api/v1/admin/reports/{tipo} |
| `/portal/admin/support` | Listar/Update estado | GET/PUT /api/v1/admin/support-tickets |
