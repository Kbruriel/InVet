## Alcance MVP

- Validar landing pública: hero, buscador, chips de categoría, cómo funciona, CTA.
- Verificar barra de búsqueda con comportamiento debounce.
- Verificar chips de categoría: estado activo y actualización de query params.
- Validar listado de clínicas: loading, error, empty, success states.
- Validar detalle de clínica para IDs válidos e inválidos.
- Probar responsive en desktop (1280x720) y mobile (375x667).
- Verificar accesibilidad: labels, botones, enlaces, foco visible, contraste.
- Confirmar que no se exponen tokens ni datos sensibles en páginas públicas.

## Fuera de alcance

- Pruebas visuales pixel-perfect.
- Integración real con backend (se usa frontend corriendo sin backend o con mocks).
- Flujo completo de agendamiento de citas.
- Autenticación en flujos públicos.
