# FE-007 — Propietarios y mascotas

## Objetivo

Portal propietario para perfil, mascotas e historial básico.

## Dependencias

- Backend relacionado: `BE-007`.
- QA relacionado: `QA-007`.
- Tokens y reglas visuales en `docs/opencode/references/frontend_visual_alignment.md`.

## Alcance MVP

- Implementar UI y consumo API del slice `007`.
- Mantener arquitectura Next.js/TypeScript/React/Tailwind.
- Reutilizar componentes desde `src/shared/ui`.
- Centralizar API en `src/shared/api`.
- Manejar loading, error, empty, success y submitting.

## Fuera de alcance

- App móvil nativa.
- Checkout en línea.
- Pasarela de pago de servicios.
- Productos, marketplace, carrito, inventario o facturación.
- Recomendaciones médicas automáticas.

## Evidencia de criterios de aceptacion

- La UI consume el contrato del slice `BE-007` (endpoints `/api/v1/owners`, `/api/v1/pets`).
- No hay Tailwind CDN en build output.
- No hay links `#` en flujos implementados (todos los botones tienen onClick).
- No se muestran acciones que contradigan permisos: owner solo ve/edita sus datos; pet endpoints validan ownership.
- No se loggean datos sensibles en logs ni tests.
- La interfaz es usable en desktop y mobile (responsive con Tailwind breakpoints).
