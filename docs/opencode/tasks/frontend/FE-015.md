# FE-015 — Reportes operativos básicos

## Objetivo

Pantallas de reportes básicos con filtros y tablas.

## Dependencias

- Backend relacionado: `BE-015`.
- QA relacionado: `QA-015`.
- Tokens y reglas visuales en `docs/opencode/references/frontend_visual_alignment.md`.

## Alcance MVP

- Implementar UI y consumo API del slice `015`.
- Mantener arquitectura Next.js/TypeScript/React/Tailwind.
- Reutilizar componentes desde `src/shared/ui`.
- Centralizar API en `src/shared/api`.
- Manejar loading, error, empty, success y submitting.

## Fuera de alcance

- App móvil nativa.
- Checkout en línea.
- Pasarela de pago de servicios.
- Productos, marketplace, carrito, inventario o facturación.
- Recomendaciones médicas automáticas.

## Actividades Frontend

1. Revisar contrato de `BE-015`.
2. Definir rutas en `src/app`.
3. Crear feature en `src/features`.
4. Crear componentes reutilizables si aplica.
5. Crear formularios con validación.
6. Integrar cliente API.
7. Manejar errores HTTP 400/401/403/404/409/422/500.
8. Agregar estados visuales.
9. Validar responsive.
10. Agregar pruebas si el repo tiene framework configurado.

## Criterios de aceptación

- La UI consume el contrato del slice o mock documentado.
- No hay Tailwind CDN.
- No hay links `#` en flujos implementados.
- No se muestran acciones que contradigan permisos conocidos.
- No se loggean datos sensibles.
- La interfaz es usable en desktop y mobile.

- [x] Estados UX implementados. — loading (spinner), error (banner `role=alert` + Reintento vía `retry`), empty (`EmptyState`), success (tabla + paginación), placeholder antes del primer `apply`. Cobertura: 32 tests en 5 suites (`api`, `useReports`, `FilterBar`, `ReportTable`, `page`).

- [x] Sin alcance fuera del MVP. — solo lectura de reportes agregados (appointments/services/pets/consultations/ratings/payments); sin export, sin gráficos, sin permisos extra, sin datos sensibles en consola (sin `console.log` en `features/reports/**`).
