# FE-001 - Base tecnica y design system

## Objetivo

Crear la base ejecutable del frontend con Next.js, Tailwind local, tokens InVet, shared UI inicial, layouts base y checks automatizados.

## Dependencias

- Backend relacionado: `BE-001`.
- QA relacionado: `QA-001`.
- Tokens y reglas visuales en `docs/opencode/references/frontend_visual_alignment.md`.

## Alcance MVP

- Crear `frontend/package.json` y scripts `lint`, `typecheck`, `test`, `build`.
- Implementar UI y consumo API base del slice `001`.
- Mantener arquitectura Next.js/TypeScript/React/Tailwind.
- Reutilizar componentes desde `src/shared/ui`.
- Centralizar API en `src/shared/api`.
- Manejar loading, error, empty, success y submitting.

## Fuera de alcance

- App movil nativa.
- Checkout en linea.
- Pasarela de pago de servicios.
- Productos, marketplace, carrito, inventario o facturacion.
- Recomendaciones medicas automaticas.

## Actividades Frontend

1. Revisar contrato de `BE-001`.
2. Crear el scaffold ejecutable en `frontend/` con Next.js, TypeScript y Tailwind local.
3. Definir rutas en `src/app`.
4. Crear feature en `src/features`.
5. Crear componentes reutilizables si aplica.
6. Crear formularios con validacion.
7. Integrar cliente API.
8. Manejar errores HTTP 400/401/403/404/409/422/500.
9. Agregar estados visuales.
10. Validar responsive.
11. Agregar pruebas automatizadas y dejar el proyecto verificable por `run-checks`.

## Criterios de aceptacion

- Existe `frontend/package.json` con scripts `lint`, `typecheck`, `test` y `build`.
- La UI consume el contrato del slice o mock documentado.
- No hay Tailwind CDN.
- No hay links `#` en flujos implementados.
- No se muestran acciones que contradigan permisos conocidos.
- No se loggean datos sensibles.
- La interfaz es usable en desktop y mobile.

## Definition of Done

- [x] Scaffold ejecutable implementado.
- [x] Rutas implementadas.
- [x] Componentes implementados.
- [x] Estados UX implementados.
- [x] Validaciones implementadas.
- [x] Consumo API centralizado.
- [x] Checks frontend pasando.
- [x] Sin alcance fuera del MVP.
