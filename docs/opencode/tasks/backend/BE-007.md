## Evidencia de criterios de aceptacion

- Contracto FE-007: API contracts documentados en `BE-007-plan.md` endpoints section y actualizados aqui.
- Routers sin logica de negocio: toda logica en use cases + repositorios; routers solo hacen Depends(), execute() y mapeo de status codes.
- Sin modelos ORM expuestos: response_models usan schemas Pydantic via `model_validate()`.
- Respuestas paginadas: todos los listados usan `page`/`page_size` con meta object.
- Errores consistentes: 401 (auth), 403 (forbidden/IDOR), 404 (not found), 409 (conflict), 422 (validation).
- Pruebas cubren happy + negative: `test_create_pet_update_and_delete_flow`, `test_clinic_role_cannot_access_pet_history`, `test_other_owner_cannot_access_pet_details`.
