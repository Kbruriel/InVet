# BE-004-T01 - Implementar perfil público de clínica/sucursal

## Capa
Backend

## Objetivo
Implementar endpoints para exponer perfiles públicos y protegidos de clínicas/sucursales.

## Dependes de
Ninguna

## Entregables
- Endpoints `/api/v1/clinics/branches/{branch_id}` (público)
- Endpoints `/api/v1/clinics/{clinic_id}/{branch_id}` (protegido)
- Uso de casos de uso para lógica de negocio
- Implementación de repositorios para acceso a datos
- Validaciones de permisos de acceso

## Criterios de aceptación
- [x] Implementado perfil público con horarios, servicios y calificaciones
- [x] Implementado perfil protegido que requiere autenticación
- [x] Separación clara entre endpoints públicos y protegidos
- [x] Arquitectura limpia siguiendo Clean Architecture (separación de capas)
- [x] No exposición directa de modelos ORM en response
- [x] Validación de errores consistente

## Validación
- [x] Tests unitarios ejecutados correctamente
- [x] Estructura de código sigue estándares del proyecto
- [x] No hay lógica de negocio en routers
