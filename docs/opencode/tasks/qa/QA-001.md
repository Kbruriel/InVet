# QA-001 - Base tecnica y design system

## Objetivo

Validar instalacion, healthcheck, build, lint, estructura y tokens.

## Dependencias

- Backend relacionado: `BE-001`.
- Frontend relacionado: `FE-001`.

## Alcance de validacion

- Happy path.
- Negative path.
- Permisos por rol.
- Ownership/tenant/branch cuando aplique.
- IDOR/BOLA.
- Estados HTTP.
- Estados UI.
- Responsive.
- Regresion del flujo principal.

## Casos minimos

1. Usuario autorizado ejecuta flujo correctamente.
2. Usuario no autenticado recibe 401 cuando aplica.
3. Usuario autenticado sin permiso recibe 403 cuando aplica.
4. Acceso cruzado por ID ajeno falla de forma segura.
5. Input invalido produce error claro sin filtrar detalles internos.
6. UI muestra loading/error/empty/success.
7. Listados aplican paginacion o limites si corresponde.

## Evidencia requerida

- Comandos ejecutados.
- Resultados esperados vs obtenidos.
- Captura textual o resumen de UI.
- Defectos con pasos de reproduccion.
- Riesgo residual si aplica.

- [x] IDOR/BOLA validado si aplica.
