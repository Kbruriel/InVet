# QA-012 — Calificaciones y comentarios

## Objetivo

Validar una reseña por cita completada y moderación básica.

## Dependencias

- Backend relacionado: `BE-012`.
- Frontend relacionado: `FE-012`.

## Alcance de validación

- Happy path.
- Negative path.
- Permisos por rol.
- Ownership/tenant/branch cuando aplique.
- IDOR/BOLA.
- Estados HTTP.
- Estados UI.
- Responsive.
- Regresión del flujo principal.

## Casos mínimos

1. Usuario autorizado ejecuta flujo correctamente.
2. Usuario no autenticado recibe 401 cuando aplica.
3. Usuario autenticado sin permiso recibe 403 cuando aplica.
4. Acceso cruzado por ID ajeno falla de forma segura.
5. Input inválido produce error claro sin filtrar detalles internos.
6. UI muestra loading/error/empty/success.
7. Listados aplican paginación o límites si corresponde.

## Evidencia requerida

- Comandos ejecutados.
- Resultados esperados vs obtenidos.
- Captura textual o resumen de UI.
- Defectos con pasos de reproducción.
- Riesgo residual si aplica.

## Definition of Done

- [x] Happy path validado. (pytest 201/200/200 + recálculo RatingSummary; Jest RatingForm/ReviewPublicList)
- [x] Negative path validado. (pytest 422 ×4, 409 ×2, 404; mensajes claros sin internals)
- [x] Permisos validados. (401 ×5 sin/invalido token; 403 owner responde/lista clínico)
- [x] IDOR/BOLA validado si aplica. (404 staff otra clínica; 403 sin clínica; 403 cita ajena; listado scoped por tenant)
- [x] Regresión mínima validada. (full suite 379 passed; Jest 51 passed; tsc exit 0)
- [x] Evidencia documentada. (`docs/opencode/qa/QA-012-results.md` — Decision: APPROVED, 2026-08-25)
