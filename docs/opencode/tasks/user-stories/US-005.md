# US-005 - Historia de usuario: Administración de clínica y sucursales

## Título

Como administrador de clínica, puedo crear, editar, listar e inactivar clínicas y sucursales con horarios, contacto y ubicación.

## Descripción

El sistema debe permitir al rol `clinic_admin` gestionar la información administrativa de clínicas y sucursales, incluyendo datos generales, horarios de atención, información de contacto y ubicación geográfica.

## Criterios de aceptación

### AC-005-01 - Crear clínica
- Dado que soy un usuario autenticado con rol `clinic_admin`
- Cuando envío un formulario válido con nombre, RFC, email, teléfono y dirección
- Entonces se crea la clínica y recibo confirmación con los datos guardados

### AC-005-02 - Actualizar clínica
- Dado que soy el owner o admin de una clínica
- Cuando edito los datos de la clínica y envío el formulario
- Entonces los cambios se reflejan inmediatamente en el panel

### AC-005-03 - Inactivar/reactivar clínica
- Dado que soy un administrador
- Cuando cambio el estado de una clínica a inactivo/activo
- Entonces el estado se actualiza y la clínica aparece deshabilitada/habilitada

### AC-005-04 - Listar clínicas
- Dado que estoy en el panel de administración
- Cuando cargo la lista de clínicas
- Entonces veo una tabla paginada con nombre, estado y acciones de editar/inactivar

### AC-005-05 - Crear sucursal
- Dado que soy owner/admin de una clínica
- Cuando creo una nueva sucursal vinculada a mi clínica
- Entonces la sucursal aparece en la lista con todos los datos ingresados

### AC-005-06 - Actualizar sucursal
- Dado que soy owner/admin de una sucursal
- Cuando edito los datos de la sucursal
- Entonces los cambios se guardan correctamente

### AC-005-07 - Gestionar horarios
- Dado que estoy en el panel de sucursal
- Cuando configuro horarios de atención por día
- Entonces los horarios se guardan sin solapamientos y se muestran correctamente

### AC-005-08 - Actualizar contacto/ubicación
- Dado que soy owner/admin de una sucursal
- Cuando actualizo teléfono, email o coordenadas
- Entonces los datos se validan y guardan correctamente

### AC-005-09 - Permisos
- Dado que soy un usuario sin rol `clinic_admin`
- Cuando intento acceder al panel de administración
- Entonces recibo un error 403 y no puedo ver los datos

### AC-005-10 - IDOR/BOLA
- Dado que soy admin de una clínica del tenant A
- Cuando intento acceder a recursos de una clínica del tenant B
- Entonces la solicitud falla con 403 y no se exponen datos cruzados

## Fuera de alcance

- Gestión de productos o inventario.
- Facturación electrónica.
- Pasarela de pago.
- Recomendaciones médicas automáticas.
- App móvil nativa.
