# US-007 — Propietarios y mascotas

## Historia de usuario

Como **propietario de una mascota**, quiero **registrar y gestionar mi perfil, mis mascotas y consultar su historial basico** para poder **administrar la informacion de mis animales desde InVet**.

## Criterios de aceptacion

### AC-007-01 — Crear perfil de propietario
- Dado que soy un usuario autenticado con rol de propietario
- Cuando solicito crear mi perfil de propietario
- Entonces se registra un registro en la tabla `owners` vinculado a mi `user_id`
- Y recibo una respuesta 201 con los datos del owner creado

### AC-007-02 — Actualizar perfil de propietario
- Dado que tengo un perfil de propietario registrado
- Cuando solicito actualizar mi perfil con nuevos datos
- Entonces se actualizan solo mis campos permitidos (nombre, email, telefono, direccion)
- Y recibo una respuesta 200 con los datos actualizados

### AC-007-03 — Registrar una mascota
- Dado que tengo un perfil de propietario registrado
- Cuando registro una mascota con nombre, especie, raza y edad
- Entonces se crea un registro en la tabla `pets` vinculado a mi `owner_id`
- Y recibo una respuesta 201 con los datos de la mascota

### AC-007-04 — Listar mis mascotas
- Dado que tengo un perfil de propietario registrado
- Cuando solicito listar mis mascotas
- Entonces recibo una respuesta 200 con una lista paginada de mis mascotas
- Y cada elemento incluye id, nombre, especie, raza y edad

### AC-007-05 — Actualizar datos de una mascota
- Dado que tengo una mascota registrada
- Cuando solicito actualizar los datos de mi mascota
- Entonces se actualizan solo los campos permitidos
- Y recibo una respuesta 200 con los datos actualizados

### AC-007-06 — Eliminar una mascota
- Dado que tengo una mascota registrada
- Cuando solicito eliminar mi mascota
- Entonces se elimina el registro de la tabla `pets`
- Y recibo una respuesta 204 sin body

### AC-007-07 — Portal propietario visible
- Dado que soy un propietario autenticado
- Cuando navego al portal propietario `/portal/owner`
- Entonces veo mi perfil y el listado de mis mascotas
- Y la interfaz muestra estados de loading, success y empty correctamente

### AC-007-08 — Formulario de mascota valida campos
- Dado que estoy en el formulario de registro de mascota
- Cuando intento guardar sin completar nombre, especie o raza
- Entonces se muestran errores de validacion claros en la UI
- Y no se envia la peticion al backend

### AC-007-09 — Historial basico de mascota
- Dado que tengo una mascota registrada con consultas medicas previas
- Cuando visualizo el detalle de mi mascota
- Entonces veo el historial basico de consultas medicas asociadas
- Y si no hay registros, se muestra un estado empty apropiado

### AC-007-10 — Acceso no autenticado rechazado
- Dado que no estoy autenticado
- Cuando intento acceder a cualquier endpoint protegido de owners/pets
- Entonces recibo una respuesta 401 Unauthorized
- Y no se expone ninguna informacion del propietario

### AC-007-11 — Clinica no accede a data de otro owner
- Dado que soy un usuario con rol de clinica
- Cuando intento acceder a los datos de un propietario que no es el mio
- Entonces recibo una respuesta 403 Forbidden o 404 Not Found
- Y no se expone informacion del otro propietario

### AC-007-12 — IDOR/BOLA en mascotas
- Dado que soy un propietario con una mascota registrada
- Cuando intento acceder a los datos de una mascota de otro propietario por ID
- Entonces recibo una respuesta 403 Forbidden o 404 Not Found
- Y no se expone informacion de la mascota ajena

### AC-007-13 — Input invalido produce error claro
- Dado que estoy registrando una mascota
- Cuando envio datos invalidos (especie vacia, edad negativa)
- Entonces recibo una respuesta 422 Unprocessable Entity
- Y el mensaje de error es claro y no filtra detalles internos del sistema

### AC-007-14 — Estados UI correctos
- Dado que estoy navegando el portal propietario
- Cuando la UI carga datos, hay errores o no hay mascotas
- Entonces se muestran los estados loading, error y empty apropiadamente
- Y la interfaz permanece usable en todos los estados

### AC-007-15 — Paginacion consistente
- Dado que tengo multiples mascotas registradas
- Cuando solicito el listado con paginacion
- Entonces recibo exactamente `page_size` items por pagina
- Y el meta incluye total, page y page_size correctos

## Dependencias

- US-002 (autenticacion y roles) — usuario debe estar autenticado con rol propietario.
- US-006 (servicios, veterinarios) — estructura de roles existente.
- BE-007 — modelos, endpoints y migraciones.
- FE-007 — portal propietario y componentes UI.
- QA-007 — criterios de validacion.

## Notas de implementacion

- El campo `user_id` en `Owner` vincula el perfil al usuario autenticado.
- El campo `owner_id` en `Pet` vincula la mascota al owner.
- La validacion de ownership se realiza en cada endpoint comparando `user_id` del token con `owner_id` de la entidad.
- Las respuestas de error no deben incluir traces, stack traces ni datos internos del sistema.
