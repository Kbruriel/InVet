## Titulo

Autenticacion y sesion

## Descripcion funcional

Permitir que una persona usuaria se registre, inicie sesion, consulte su perfil autenticado, renueve su sesion, cierre sesion y solicite recuperacion de password sin exponer datos sensibles. Esta historia habilita los roles iniciales del MVP para que los slices posteriores puedan proteger recursos privados.

## Usuarios/roles involucrados

- **Visitante anonimo**: necesita registrarse, iniciar sesion o recuperar acceso.
- **Usuario autenticado**: necesita consultar su perfil y mantener una sesion vigente.
- **Administrador inicial**: necesita que el backend distinga roles base para flujos privados posteriores.
- **QA**: necesita validar tokens, errores, permisos y estados UI con evidencia reproducible.
