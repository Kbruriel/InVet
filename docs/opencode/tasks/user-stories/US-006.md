# US-006 — Servicios, veterinarios y usuarios internos

## Objetivo

Historias de usuario y criterios de aceptacion derivados del slice 006 para servicios, veterinarios y usuarios internos.

## Historias de Usuario

### US-006-1: Gestionar servicios de la clinica

**Como** administrador de clinica  
**Quiero** crear, editar, listar y desactivar servicios  
**Para** mantener actualizada la oferta de servicios de mi clinica

#### Criterios de Aceptacion

- **AC-006-01**: Como admin, puedo crear un servicio con nombre, descripcion, precio y duracion; el sistema responde 201 y el servicio aparece en listados.
- **AC-006-02**: Como admin, puedo editar los datos de un servicio existente; el sistema actualiza y mantiene el historial.
- **AC-006-03**: Como admin o usuario autenticado, puedo listar servicios paginados filtrados por clinica; el sistema responde con metadatos de paginacion.
- **AC-006-04**: Como admin, puedo desactivar un servicio; el servicio deja de aparecer en listados activos pero permanece accesible para consulta con filtro explicito.
- **AC-006-05**: Como usuario sin permiso, intento crear un servicio; el sistema responde 403.
- **AC-006-06**: Como usuario no autenticado, intento acceder a cualquier endpoint de servicios; el sistema responde 401.

### US-006-2: Gestionar veterinarios de la clinica

**Como** administrador de clinica  
**Quiero** registrar, editar, listar y desactivar veterinarios  
**Para** mantener actualizado el equipo profesional de mi clinica

#### Criterios de Aceptacion

- **AC-006-07**: Como admin, puedo crear un veterinario con nombre, licencia profesional, especialidad; el sistema responde 201 y valida unicidad de licencia por clinica.
- **AC-006-08**: Como admin, puedo editar los datos de un veterinario existente; el sistema actualiza sin afectar asignaciones existentes.
- **AC-006-09**: Como admin o usuario autenticado, puedo listar veterinarios paginados filtrados por clinica; el sistema responde con metadatos de paginacion.
- **AC-006-10**: Como admin, puedo desactivar un veterinario; el veterinario deja de aparecer en listados activos pero sus asignaciones se preservan.
- **AC-006-11**: Como usuario sin permiso, intento crear un veterinario; el sistema responde 403.
- **AC-006-12**: Como usuario no autenticado, intento acceder a cualquier endpoint de veterinarios; el sistema responde 401.

### US-006-3: Gestionar usuarios internos de la clinica

**Como** administrador de clinica  
**Quiero** registrar, editar, listar y desactivar usuarios internos vinculados a cuentas de autenticacion  
**Para** controlar el acceso interno de mi clinica

#### Criterios de Aceptacion

- **AC-006-13**: Como admin, puedo crear un usuario interno vinculandolo a una cuenta de autenticacion existente; el sistema responde 201 y valida que user_id exista.
- **AC-006-14**: Como admin, puedo editar el rol y sucursales de un usuario interno; el sistema actualiza los permisos asociados.
- **AC-006-15**: Como admin o usuario autenticado, puedo listar usuarios internos paginados filtrados por clinica; el sistema responde con metadatos de paginacion.
- **AC-006-16**: Como admin, puedo desactivar un usuario interno; el usuario pierde acceso a recursos internos pero su historial se preserva.
- **AC-006-17**: Como usuario sin permiso, intento crear un usuario interno; el sistema responde 403.
- **AC-006-18**: Como usuario no autenticado, intento acceder a cualquier endpoint de usuarios internos; el sistema responde 401.

### US-006-4: Asignar servicios a veterinarios

**Como** administrador de clinica  
**Quiero** asignar y desasignar servicios a veterinarios  
**Para** indicar que un veterinario puede atender ciertos servicios

#### Criterios de Aceptacion

- **AC-006-19**: Como admin, puedo asignar un servicio de mi clinica a un veterinario de mi clinica; el sistema responde 201 y la asociacion queda activa.
- **AC-006-20**: Como admin, intento asignar un servicio de otra clinica a un veterinario mio; el sistema responde 403 por violacion de tenant.
- **AC-006-21**: Como admin, puedo desasignar un servicio de un veterinario; la asociacion se elimina y el veterinario ya no aparece en listados de ese servicio.
- **AC-006-22**: Como usuario sin permiso, intento asignar un servicio a un veterinario; el sistema responde 403.

### US-006-5: Asignar sucursales a usuarios internos

**Como** administrador de clinica  
**Quiero** asignar y desasignar sucursales a usuarios internos  
**Para** controlar a que sucursales tiene acceso cada usuario interno

#### Criterios de Aceptacion

- **AC-006-23**: Como admin, puedo asignar una sucursal de mi clinica a un usuario interno mio; el sistema responde 201 y la asociacion queda activa.
- **AC-006-24**: Como admin, intento asignar una sucursal de otra clinica a un usuario interno mio; el sistema responde 403 por violacion de tenant.
- **AC-006-25**: Como admin, puedo desasignar una sucursal de un usuario interno; la asociacion se elimina pero el usuario mantiene otras asignaciones.
- **AC-006-26**: Como usuario sin permiso, intento asignar una sucursal a un usuario interno; el sistema responde 403.

### US-006-6: Experiencia de usuario en vistas admin

**Como** administrador de clinica  
**Quiero** ver estados claros de carga, error, vacio y exito en todas las pantallas de gestion  
**Para** tener confianza en el estado de la aplicacion y saber cuando actuar

#### Criterios de Aceptacion

- **AC-006-27**: Como admin, navego a cualquier vista admin; la UI muestra loading mientras se consumen datos y success/error segun corresponda.
- **AC-006-28**: Como admin, cuando un listado esta vacio, la UI muestra un mensaje claro indicando que no hay registros.
- **AC-006-29**: Como admin, cuando un formulario tiene errores de validacion, la UI muestra mensajes por campo sin exponer detalles internos del servidor.
- **AC-006-30**: Como admin con rol insuficiente, las acciones de crear/editar/eliminar se ocultan o deshabilitan en la UI.
- **AC-006-31**: La interfaz es usable en mobile (375px) y desktop (1440px) sin perdida de funcionalidad critica.
