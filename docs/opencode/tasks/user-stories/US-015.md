# US-015 — Reportes operativos básicos

## Historia principal

Como **admin o propietario de clinica**, quiero **consultar reportes basicos operativos por periodo** (citas, servicios, mascotas, consultas, calificaciones y pagos) para **monitorear el estado operativo de la clinica**.

## Subhistorias AC

| ID | Historia | Criterios asociados |
| --- | --- | --- |
| AC-015-01 | Como admin, filtro reportes por tipo y rango de fechas y obtengo totales agregados. | AC-015-01, AC-015-02 |
| AC-015-02 | Como admin, navego pagina a pagina o recibo limite maximo para listados extensos. | AC-015-03 |
| AC-015-03 | Como admin, consulto el reporte de citas con campos resumidos (id, fecha, veterinario, estado, tipo Servicio) paginados. | AC-015-04 |
| AC-015-04 | Como admin, consulto el reporte de servicios realizados con campos resumidos paginados. | AC-015-05 |
| AC-015-05 | Como admin, consulto el conteo de mascotas activas por periodo o general. | AC-015-06 |
| AC-015-06 | Como admin, consulto el reporte de consultas medicas con campos resumidos paginados. | AC-015-07 |
| AC-015-07 | Como admin, consulto el resumen de calificaciones promedio por veterinario y clinica. | AC-015-08 |
| AC-015-08 | Como admin, consulto el reporte de pagos operativos con campos resumidos paginados. | AC-015-09 |
| AC-015-09 | Como usuario sin tokens válido, no puedo acceder a ningun endpoint de reportes. | AC-015-10 |
| AC-015-10 | Si solicito un `report_type` desconocido, obtengo 422 con mensaje claro. | AC-015-11 |
