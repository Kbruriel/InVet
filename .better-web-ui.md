# Contexto de diseño InVet

- Audiencia: personal de clínica, administradores operativos y supervisores que revisan reportes diarios y por periodo.
- Tono: claro, confiable, eficiente y profesional; el sistema debe sentirse calmado, no urgente.
- Dirección visual: paleta teal/mint/sand, tipografía Plus Jakarta Sans, radios tipo pill, sombras suaves y superficies cálidas.
- UI: una acción principal por pantalla, jerarquía fuerte, tablas legibles, filtros visibles y estados completos de carga, vacío, error, éxito y deshabilitado.
- Implementación: Next.js + TypeScript + React + Tailwind, reutilizando `src/shared/ui` y centralizando llamadas en `src/shared/api`.
- Reglas: no usar lenguaje de disponibilidad en tiempo real si no existe, no mostrar navegación privada a visitantes anónimos y mantener las rutas reales del producto.
