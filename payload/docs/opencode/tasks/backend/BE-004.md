# BE-004 - Public clinic/branch profile

## Objective

Expose a public clinic/branch profile with services, schedules, rating summary, and basic availability.

## MVP scope

- Public endpoints under `/api/v1`.
- Include:
  - Available schedules
  - Offered services
  - Rating summary
  - Basic availability
- Do not include sensitive data, checkout, cart, or payment flows.

## Endpoints

### Public branch profile

`GET /api/v1/clinics/branches/{branch_id}`

- No authentication required.
- Returns public branch data, services, schedules, and rating summary.

### Protected branch profile

`GET /api/v1/clinics/{clinic_id}/{branch_id}`

- Requires authentication.
- Returns the same payload with access validation for the authenticated user.

## Acceptance notes

- Routers stay free of business logic.
- No ORM models are exposed in responses.
- Errors stay consistent and do not leak internal details.
- Tests cover happy path and negative path.
